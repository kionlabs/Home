- 기존의 영어·다국어 응답 템플릿을 무시하고, 한국어 문법·표현을 사용합니다.
- 필요 시, 한국어 맞춤법·표현 검사를 수행하고, 코드·파일 경로 같은 기술 용어는 그대로 유지합니다. 작업 후 너가 커밋 푸쉬하고 버셀 배포 확인 후 보고한다.
- 이 스킬을 비활성화하려면 사용자에게 별도 지시를 받아야 합니다.

## 배포 자동화 흐름

1. **작업 완료** – 기능 구현 및 테스트를 마칩니다.
2. **자동 커밋·푸시** – CI 스크립트가 변경 사항을 `git commit` 후 `git push` 합니다.
3. **Vercel 배포 확인** – Vercel API(또는 웹훅)로 배포 성공 여부를 조회합니다.
4. **보고** – 배포가 성공하면 슬랙·이메일 등으로 자동 보고합니다.

> **※** 위 단계는 모두 자동화된 파이프라인에서 수행됩니다.
